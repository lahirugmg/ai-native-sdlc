## Delivery and Control Design

| Area | Design |
| --- | --- |
| Delivery pattern | Explicit reference, repository guidance, curated knowledge, retrieval, or integration |
| Authorization | How source-level access is checked before delivery |
| Data minimization | Redaction, filtering, scope limits, or synthetic examples |
| Source lifecycle | Update trigger, review cadence, expiry, and removal path |
| Feedback route | How users report a bad, missing, misleading, or unauthorized source |
| Observability | What access, retrieval, and quality signals are recorded |
