# Diagrams

Source-controlled diagrams that summarize the journey guidance. They restate what the
horizon guides already say; the guides remain the source of truth when the two disagree.

| Diagram | Summarizes | Generated by |
| --- | --- | --- |
| [ai-native-sdlc-big-picture.excalidraw](ai-native-sdlc-big-picture.excalidraw) | The three horizons and their gates, the pre-plan / execution / validation loop that runs inside each one, and the governance frame that encloses both | [tools/build-big-picture-diagram.py](../../tools/build-big-picture-diagram.py) |

## Working With Generated Diagrams

The big-picture diagram is generated so that its wording stays reviewable in a diff and
stays consistent with the guides it summarizes. Edit the content blocks in the generator,
then regenerate:

```
python3 tools/build-big-picture-diagram.py
```

Hand edits made in a drawing editor are overwritten on the next run. A diagram whose
wording has drifted from its guide is a stale context product, which is the failure mode
that [Medium term: Context engineering](../medium-term-context-engineering.md) exists to
prevent.

## Reading the Big Picture

- **Horizons are entered on evidence.** The gate diamonds carry the advancement criteria
  from [Journey to AI-native SDLC](../journey-to-ai-native-sdlc.md). They are not
  reached by elapsed time, headcount, or tool rollout.
- **The loop is the unit of work.** Pre-plan, execution, and validation repeat inside
  every horizon. What changes across horizons is who supplies the context and how much of
  the loop is automated, never whether validation happens.
- **Governance encloses the diagram rather than terminating it.** The controls named along
  the bottom are design inputs, applied in proportion to impact as described in
  [Governance and Risk](../governance-and-risk.md).
